# 오아로 광고 랜딩

중국어 `/cn/event/`, 대만 `/tw/event-august/`, 영어 `/en/event/`, 위챗 안내 `/cn/wechat/`의 운영 원본이다.
2026-11-01 운영 배포의 공개 파일을 SHA-1 대조 후 복원했다. 복원 커밋과 오류 수정 커밋을 구분한다.

## 수정·배포

- `codex/` 브랜치 → `npm run build` → PC 1440px·모바일 360/390px 확인 → PR. 운영 배포는 대표 승인 후 진행한다.
- `npm run check`는 모든 언어 페이지의 로컬 이미지·스크립트·스타일 파일과 루트 이동 대상을 검사한다. 파일이 빠지면 빌드도 실패한다.
- 배포 파일은 `dist/`에 생성한다. 기존 Vercel 프로젝트 `oaro-tw-event`를 사용하고, 루트의 대만 이벤트 이동·언어별 주소·측정/문의 코드 전달을 보존한다.
- 대표 사진의 기준 주소는 `/hero.webp`. 기존 언어별 복사본과 QR 파일도 유지한다.
- 모바일은 본문 상담/행사 버튼이 보일 때만 플로팅 상담 버튼을 숨긴다. 본문 버튼을 지나면 다시 표시한다. PC 상담과 키보드 포커스는 유지한다.
- 행사 기한·할인·가격·연락처·측정 ID를 근거 없이 변경하지 않는다. 대만의 종료 안내를 새 행사처럼 바꾸지 않는다.

## 확인 범위

배포 전 파일 검사는 반복 가능하게 구현했다. 정기적인 외부 랜딩/이미지 HTTP 감시·열톡 알림은 이 저장소만으로 실행되지 않는다. 별도의 기존 수집기 연동과 운영 검증이 필요하다.
